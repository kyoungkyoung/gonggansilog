## 2026-03-30

### 1. 서버 실행
- Django 개발 서버 실행 (`python3 manage.py runserver`)
- 포트: 8000

### 2. 관리자 페이지 블록체인 섹션 추가
**수정 파일:** `contracts/admin.py`

- 계약 목록에 "블록체인" 컬럼 추가
  - 확정됨 (초록색)
  - 처리중 (노란색)
  - 실패 (빨간색)
  - 미확정 (회색)
- 계약 상세페이지에 "블록체인 증거화" 섹션 추가 (펼쳐진 상태)
  - 계약 확정 여부
  - 확정 시점
  - 블록체인 상태
  - 트랜잭션 해시
  - 최종 해시
  - 앵커링 시점
  - 파일별 해시 메타데이터
- 필터에 블록체인 관련 항목 추가
  - 계약 확정 여부
  - 블록체인 상태

### 3. 관리자 페이지 UI 전면 개편
레퍼런스 이미지(`reference/img/admin_dashboard.png`, `reference/img/admin_user.png`) 기반으로 커스텀 디자인 적용

**생성한 파일:**

#### `templates/admin/base_site.html`
- 커스텀 사이드바 레이아웃
- 전체 CSS 스타일링
- 왼쪽: 어두운 사이드바 (240px)
  - 로고 (공간실록)
  - 사용자 정보 (이메일, 역할)
  - 메뉴 (대시보드, 사용자 관리, 계약 관리 등)
  - 로그아웃 버튼
- 오른쪽: 밝은 컨텐츠 영역
- 현재 페이지 메뉴는 파란색으로 강조

#### `templates/admin/index.html`
- 대시보드 페이지
- 통계 카드 4개 (전체 계약, 활성 계약, 전체 사용자, 블록체인 확정)
- 최근 계약 / 최근 입실퇴실 기록 카드

#### `templates/admin/login.html`
- 로그인 페이지
- 중앙 정렬 깔끔한 폼
- 로고 + 타이틀 + 서브타이틀
- 브레드크럼, 사이드바 숨김

### 4. CSS 세부 수정

#### select 태그
```css
select {
    height: 100%;
    margin: 0;

```

#### 검색 폼 (#changelist-search)
- label 숨김
- 검색창 + 버튼 가로 한 줄 배치
- 높이 40px 통일

#### input 태그
- max-width: 100% (끝까지 늘어나도록)

#### .form-row > div
- width: 100% (input이 전체 너비 사용하도록)
