## 📋 PART 1. 계약 전 (入居前)

  - [ ] 입주 예정일

- [ ] **신청인 정보 준비**

  - [ ] 생년월일

- [ ] **연대보증인 정보** (필요한 경우)

  - [ ] 신청인과의 관계

- [ ] **본인확인 서류 준비**

## 📋 PART 2. 계약 중 (入居中)

### 2-1. 사용 목적 및 금지·제한 행위

- [ ] **거주 전용** 목적으로만 사용 (제3조)

- [ ] **절대 금지 행위 (별표 제1)** 숙지
  - [ ] 총포·도검류, 폭발성·발화성 위험물 제조·보관 금지
  - [ ] 대형 금고 등 중량물 반입·설치 금지
  - [ ] 배수관 부식 가능 액체 방류 금지
  - [ ] TV·스테레오 큰 소리, 피아노 등 악기 연주 금지
  - [ ] 맹수·독사 등 위험 동물 사육 금지
  - [ ] 반사회적 세력 관련 사용 금지 (사무소 제공, 거주, 출입)

- [ ] **임대인 승낙 필요 행위 (별표 제2)** 숙지
  - [ ] 관상어·작은 새 외 동물(개·고양이 등) 사육
  - [ ] 공용장소 물건 방치
  - [ ] 공용장소 간판·포스터 게시

- [ ] **임대인 통지 필요 행위 (별표 제3)** 숙지
  - [ ] 동거인 추가 (출생 제외)
  - [ ] 1개월 이상 계속 비우기

- [ ] **서면 승낙 없이 금지**
  - [ ] 임차권 양도·전대 금지
  - [ ] 증축·개축·이전·개조·내장 공사 금지
  - [ ] 부지 내 공작물 설치 금지

---

### 2-2. 월세·공익비 지불 관리

- [ ] **월세** 지불기한 준수
- [ ] **공익비** 지불기한 준수
- [ ] 1개월 미만 기간은 30일 기준 일할계산
- [ ] 월세 개정 사유 발생 시 **협의** 진행
  - [ ] 세금·부담금 증감
  - [ ] 건물 가격 변동
  - [ ] 인근 동류 건물 월세와의 비교

---

### 2-3. 수리 관련 (제9조)

- [ ] **수리 필요 부위 발견 시** → 임대인에게 통지 및 협의
- [ ] **임대인 수리 시** → 사전 통지 받고, 정당한 이유 없이 거부 불가
- [ ] **임대인이 수리 안 할 경우** → 임차인이 직접 수리 가능 (비용 부담 규정 확인)

- [ ] **임차인이 직접 할 수 있는 경미한 수리 (별표 제4)**
  - [ ] 전구·형광등 교체
  - [ ] 퓨즈 교체
  - [ ] 수도꼭지 패킹·스템 홀더 교체
  - [ ] 욕실 등 고무마개·사슬 교체
  - [ ] 기타 비용이 경미한 수리
  - → 임대인 통지·승낙 불필요, 비용은 임차인 부담

---

### 2-4. 임대인의 출입 (제16조)

- [ ] 방화·구조 보전·관리상 필요 시 → **사전 승낙** 후 출입
- [ ] 화재 등 **긴급 시** → 사전 승낙 없이 출입 가능 (부재 시 사후 통지)
- [ ] 차기 임차 희망자·양수 희망자의 사전조사 → **사전 승낙** 후 출입

---

### 2-5. 계약 해제 사유 숙지 (제10조)

- [ ] 월세·공익비 미납 → 최고 후 해제 가능
- [ ] 사용목적 위반, 금지행위 → 최고 후 + 계약 지속 곤란 시 해제
- [ ] 반사회적 세력 관련 → **최고 없이 즉시 해제**

---

### 2-6. 임차인의 해약 (제11조)

- [ ] 해약 시 **최소 30일 전** 해약 신청 필요
- [ ] 또는 **30일분 월세** 지불하면 즉시 해약 가능

---

### 2-7. 정기임대차 계약의 경우 추가 사항

- [ ] **계약 종료 통지** 확인
  - [ ] 임대인이 만료 1년 전~6개월 전 사이에 서면 통지
  - [ ] 통지 미수령 시 → 통지일로부터 6개월 후 종료
- [ ] **재계약 의향** 확인
  - [ ] 통지서에 재계약 의사 부기 여부 확인

## 📋 PART 3. 계약 후 / 퇴거 시 (退去時)

### 3-1. 퇴거 절차

- [ ] 퇴거 날짜를 **사전에 임대인에게 통지**
- [ ] 계약 종료일까지 퇴거 완료 (해제된 경우 즉시)
- [ ] 열쇠 반환

---

### 3-2. 원상회복 기본 원칙 (제15조 / 별표 제5)

> **핵심 원칙**: 통상적 사용에 의한 손모(통상손모)와 경년변화는 **임대인 부담**.
> 임차인의 고의·과실·선관주의 의무 위반에 의한 손모는 **임차인 부담**.

---

### 3-3. 임대인이 부담하는 것 (원상회복 불필요)

#### 바닥 (다다미·마루·카펫)
- [ ] 다다미 뒤집기·표면 교체 (자연 열화)
- [ ] 마루 왁스칠
- [ ] 가구 설치에 의한 바닥·카펫 파임·설치 흔적
- [ ] 다다미·마루 변색 (일조, 건물 구조 결함에 의한 것)

#### 벽·천장 (벽지 등)
- [ ] TV·냉장고 뒤쪽 까만 자국 (덴키야케)
- [ ] 벽에 붙인 포스터·그림 흔적
- [ ] 압정·핀 구멍 (보드 교체 불필요한 정도)
- [ ] 에어컨(임차인 소유) 설치 나사구멍·흔적
- [ ] 벽지 변색 (일조 등 자연현상)

#### 창호·후스마·기둥
- [ ] 방충망 교체 (자연 열화)
- [ ] 지진으로 파손된 유리
- [ ] 망유리 균열 (구조에 의한 자연 발생)

#### 설비·기타
- [ ] 전문업자 하우스 클리닝 (통상적 청소를 한 경우)
- [ ] 에어컨 내부 세정 (냄새 미부착)
- [ ] 소독 (부엌·화장실)
- [ ] 욕조·보일러 교체 (수명에 의한 것)
- [ ] 열쇠 교체 (분실·파손 없는 경우)
- [ ] 설비기기 고장 (기기 수명에 따른 것)

---

### 3-4. 임차인이 부담하는 것 (원상회복 필요)

#### 바닥
- [ ] 카펫에 음료 엎질러 생긴 얼룩·곰팡이 (손질 부족)
- [ ] 냉장고 아래 녹슨 흔적 (방치로 인한 오손)
- [ ] 이사 작업 등으로 인한 긁힌 자국
- [ ] 마루 변색 (부주의로 비가 들이침)

#### 벽·천장
- [ ] 청소 태만으로 인한 부엌 기름때
- [ ] 결로 방치로 악화된 곰팡이·얼룩
