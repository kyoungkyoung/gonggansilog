# PRD: 상가 원상복구 기록 관리 서비스

## 1. 제품 개요

### 1.1 배경 및 문제점
- 상가 임대차 계약 종료 시 원상복구 의무로 인한 임대인-임차인 간 분쟁 빈번 발생
- 입실 당시 상태에 대한 객관적 증거 부족
- 임차인의 개인 사진은 법적 증거력 부족 및 위변조 가능성
- 임대인 입장에서도 자산 보호를 위한 명확한 기록 필요

### 1.2 솔루션
**오프라인에서 계약한 상가의** 입실 시점 상태를 디지털 인벤토리로 기록하여 퇴실 시 객관적 비교 근거를 제공하는 웹 서비스

### 1.3 참고 모델
쏘카의 차량 대여 전후 상태 기록 시스템

### 1.4 서비스 포지셔닝
- 기존 부동산 플랫폼(네이버 부동산, 직방, 다방 등)의 **보완재**
- 상가 검색은 기존 플랫폼 활용, 계약 후 원상복구 관리는 우리 서비스 이용

## 2. 사용자 정의

### 2.1 타겟 사용자
- **임차인**: 소상공인, 자영업자 (상가를 임대하는 사람)
- **임대인**: 상가 건물주, 부동산 소유자

## 3. 핵심 기능 요구사항

### 3.1 임차인 기능

#### 3.1.1 계약 정보 등록
- 계약한 상가 정보 입력
  - 상가 주소
  - 계약일
  - 입실일/퇴실 예정일
  - 임대인 정보 (이름, 연락처)
  - 계약서 사본 업로드 (선택)
- 임대인 초대 기능 (이메일/SMS)

#### 3.1.2 입실 기록 생성
- **계약 후 입실 시점** 매장 상태 촬영
- 촬영 항목 가이드 제공:
  - 벽면 (4면)
  - 바닥
  - 천장
  - 화장실
  - 주방/싱크대
  - 전기/설비 시설
  - 외부 간판 설치 부위
  - 출입문/창문
  - 기타 특이사항
- 사진 메타데이터 자동 기록:
  - 촬영 일시
  - GPS 위치
  - 촬영 기기 정보
- 각 사진에 카테고리 및 메모/설명 추가 기능
- 임대인과 공유 및 확인/서명 요청

#### 3.1.3 퇴실 기록 생성
- 입실 기록과 동일한 항목 촬영 가이드
- 입실 사진과 나란히 비교 뷰 제공
- 차이점 하이라이트 기능
- 임대인과 공유 및 확인/서명 요청

#### 3.1.4 기록 관리
- 내 계약 목록 조회
- 각 계약별 입실/퇴실 기록 열람
- 기록 다운로드 (PDF, 이미지 압축파일)
- 기록 공유 링크 생성

### 3.2 임대인 기능

#### 3.2.1 초대 수락
- 임차인의 초대 링크/이메일로 가입 및 연결
- 또는 독립적으로 가입 후 임차인과 연결

#### 3.2.2 입실/퇴실 기록 확인
- 임차인이 생성한 입실 기록 검토
- 기록 승인/이의제기 (의견 남기기)
- 퇴실 기록 검토 및 원상복구 상태 확인
- 디지털 서명 기능

#### 3.2.3 자산 기록 관리
- 내 보유 상가별 임대 이력 조회
- 각 상가의 과거 입실/퇴실 기록 아카이브
- 동일 상가의 시간에 따른 상태 변화 추적

### 3.3 공통 기능

#### 3.3.1 인증 및 보안
- 회원가입/로그인 (임대인/임차인 구분)
- 본인 인증 (휴대폰, 이메일)
- 디지털 서명 기능

#### 3.3.2 데이터 무결성
- 사진 위변조 방지 (해시값 기록)
- 타임스탬프 보장
- 법적 효력을 위한 제3자 인증 검토 (향후)

#### 3.3.3 분쟁 해결 지원
- 입실/퇴실 기록 비교 리포트 자동 생성
- 차이점 하이라이트
- 양측 의견 기록
- 제3자(중재인) 열람 링크 생성 (향후)

## 4. 사용자 플로우

### 4.1 임차인 플로우
```
1. 오프라인에서 상가 탐색 (네이버, 직방, 부동산 중개소 등)
2. 마음에 드는 상가 발견 및 계약 진행
3. 계약 완료
4. 우리 서비스 가입/로그인
5. 계약 정보 입력 및 임대인 초대
6. 입실 시점 사진 촬영 및 업로드 (가이드 따라)
7. 임대인에게 확인 요청 알림 발송
8. 임대인 승인 대기 (또는 임대인 미가입 시 기록만 보관)
9. 영업 기간 동안 기록 보관
10. 퇴실 시점 사진 촬영 및 업로드
11. 입실 기록과 자동 비교 뷰 확인
12. 임대인 확인 요청
13. 양측 승인 후 기록 다운로드 및 최종 보관
```

### 4.2 임대인 플로우
```
1. 임차인으로부터 초대 링크/이메일 수신
2. 회원가입/로그인
3. 임차인의 입실 기록 확인 요청 알림 수신
4. 입실 기록 검토 (현장 확인 후)
5. 승인 또는 이의제기 (의견 작성)
6. 양측 합의 후 최종 승인
7. 임대 기간 동안 기록 보관
8. 퇴실 시점 기록 확인 요청 알림 수신
9. 퇴실 기록 검토 (입실 기록과 비교)
10. 원상복구 상태 확인 및 승인/이의제기
11. 양측 합의 후 최종 승인
12. 기록 아카이브 보관
```

### 4.3 엣지 케이스
- **임대인이 서비스 미가입 시**: 임차인만 기록 생성/보관 가능, 나중에 분쟁 시 증거로 활용
- **승인 기한**: 확인 요청 후 7일 이내 미응답 시 자동 승인 또는 일방적 기록 보관

## 5. 비기능 요구사항

### 5.1 성능
- 사진 업로드: 10MB 이하 파일 3초 이내 업로드
- 페이지 로딩: 3초 이내
- 이미지 로딩 최적화 (썸네일, lazy loading)

### 5.2 보안
- HTTPS 통신
- 사진 데이터 암호화 저장
- 개인정보보호법 준수
- 접근 권한 관리 (본인 계약 기록만 열람)

### 5.3 호환성
- **모바일 웹 우선** (현장에서 촬영하므로)
- iOS Safari, Android Chrome 최신 버전 지원
- 카메라 API 지원
- 데스크톱 브라우저 지원 (Chrome, Safari, Edge)

### 5.4 확장성
- 동시 접속자 1,000명 처리
- 향후 10만 건 이상의 기록 저장 가능
- 사진 저장소 확장 가능 구조

## 6. MVP 범위

### Phase 1 (MVP) - 핵심 기록 관리 기능
- 임차인/임대인 회원가입 및 로그인
- 계약 정보 등록
- 입실 기록 생성 (사진 촬영/업로드, 카테고리, 메타데이터 기록)
- 퇴실 기록 생성
- 입실/퇴실 기록 나란히 비교 뷰
- 임대인 초대 및 확인/승인 기능
- 기록 다운로드 (PDF, 이미지 ZIP)
- 기본적인 데이터 무결성 (타임스탬프, 메타데이터)

### Phase 2 - 고도화
- AI 기반 차이점 자동 감지 및 하이라이트
- 블록체인 기반 데이터 무결성 강화
- 법무법인 자문을 통한 법적 효력 강화
- 공증 서비스 연계 (유료 옵션)
- 중재 서비스 연계
- 알림 기능 강화 (SMS, 카카오톡)

### Phase 3 - 생태계 확장
- **사용자 기반 상가 매물 공유 기능** (커뮤니티)
- 임대차 계약서 통합 관리
- 보험 상품 연계
- 부동산 플랫폼 제휴/API 연동
- B2B 서비스 (부동산 중개업소, 프랜차이즈 본사 등)

## 7. 기술 스택 제안

### Frontend
- **Next.js** (React 기반, SEO, 모바일 최적화)
- **TailwindCSS** (빠른 UI 개발)
- **PWA** 지원 (모바일 앱처럼 사용)

### Backend
- **Node.js + NestJS** 또는 **Python + FastAPI**
- RESTful API
- JWT 기반 인증

### Database
- **PostgreSQL** (계약, 사용자, 기록 메타데이터)
- **AWS S3** 또는 **Cloudflare R2** (사진 저장)

### Infrastructure
- **Vercel** (Frontend) + **AWS/GCP** (Backend)
- **CDN** (이미지 전송 최적화)
- **GitHub Actions** (CI/CD)

### 기타
- **Sharp** 또는 **ImageMagick** (이미지 리사이징, 썸네일)
- **ExifReader** (사진 메타데이터 추출)
- **jsPDF** (PDF 생성)

## 8. 성공 지표 (KPI)

### Phase 1 목표 (6개월)
- 가입자 수: 500명 (임차인 300, 임대인 200)
- 월간 입실 기록 생성: 50건
- 양측 승인 완료율: 60% 이상
- 사용자 만족도 (NPS): 40 이상

### 장기 목표
- 연간 계약 기록 건수: 10,000건
- 분쟁 해결 기여도: 설문 조사 통해 80% 이상이 "도움됨"
- 재방문율: 임대인 70% 이상 (여러 임차인과 계약)

## 9. 비즈니스 모델

### 무료 서비스 (MVP)
- 기본 기록 생성 및 관리 무료
- 초기 사용자 확보 집중

### 유료 옵션 (Phase 2 이후)
- **프리미엄 기능**: AI 차이점 감지, 공증 서비스 연계 (건당 ₩10,000~30,000)
- **임대인 구독**: 여러 상가 관리, 무제한 기록 보관 (월 ₩9,900)
- **B2B**: 부동산 중개업소, 프랜차이즈 대량 계약 (별도 협의)

## 10. 리스크 및 고려사항

### 10.1 법적 리스크
- 디지털 기록의 법적 효력 검증 필요
- **변호사/법무법인 자문 필수**
- 개인정보 처리방침 철저히 준수

### 10.2 채택 장벽
- **양측 모두 사용해야 효과 극대화**
  - 대응: 임차인 단독 사용도 가치 제공 (증거 자료)
- 사용 습관 형성 필요
  - 대응: 온보딩 가이드, 튜토리얼 강화

### 10.3 초기 사용자 확보 전략
- **임차인 우선 타겟**: 본인의 권익 보호에 더 민감
- 소상공인 커뮤니티, 창업 카페 등에서 홍보
- 부동산 중개업소와 제휴 (계약 시 추천)
- "원상복구 분쟁 사례" 콘텐츠 마케팅

### 10.4 경쟁
- 아직 명확한 직접 경쟁자 부재 (기회)
- 대형 플랫폼의 모방 가능성 (빠른 시장 선점 필요)
